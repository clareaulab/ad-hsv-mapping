# Mapping HSV-1 reactivation in brains and related tissues

This repo contains the raw LoganSearch queries, custom post-processing scripts, and downstream single-cell analyses of the HSV-1 reactivation hit.  

See Gutierrez et al. bioRxiv 2026.
